Monitor Globe - 3D Server Monitoring

This demonstrates a 3D globe showing server monitors at their physical locations worldwide.

Features Implemented:

  • ✅ 3D Globe with realistic Earth appearance
  • ✅ Monitor locations plotted using coordinates
  • ✅ getCityCoordinates function with OpenStreetMap Nominatim API
  • ✅ Fallback coordinates for network-restricted environments
  • ✅ Error handling for API failures
  • ✅ Auto-rotation and zoom controls
  • ✅ Colored status indicators (green=online, red=offline, yellow=selected)
  • ✅ Side panel for detailed monitor information
  • ✅ Monitor usage data visualization (CPU, RAM, disk, network)
  • ✅ Coordinate caching to reduce API calls
  • ✅ Interactive monitor selection
